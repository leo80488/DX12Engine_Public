# 状態と制限事項

- シングルウィンドウ、シングルビューポート。
- 自動テストなし。
- **主要な可視性判定はラスタライズベース** — DXR は DDGI のインライン `RayQuery` トレースとそのフレームごとの TLAS でのみ使用される。完全な RTPSO + SBT パスは `Raytracing.cpp` に存在するが、現在は未使用。
- **ホットリロード** は一部のパスに対して組み込まれている（コアの G-Buffer / Lighting / Shadow グループは即時、その他いくつかは遅延）。手書き PSO を持つコンピューター専用パスは、参加させるために明示的なオプトインが必要。
- **アニメーション** — リニアブレンドスキニングのみ（デュアルクォータニオンなし）。モーフターゲット、CCD IK + 接地を考慮した足 IK、MMD の回転付与ボーン、ステートごとのクロスフェード FSM がその上に重ねられている。汎用のブレンドツリー / ステートグラフのオーサリングツールはない。
- **物理** — ラグドールはまだ未実装（`Ragdoll` オブジェクトレイヤーは予約済みだが未使用）。
- **オーディオ** — PCM `.aclip` のみ。圧縮 / ストリーミングコーデックは予約済みだが未実装。`StopVoice` のフェードアウトはまだ実際のボリュームランプになっていない。
- **ビデオ** — ハードウェア D3D12 デコード（FFmpeg D3D12VA または `ID3D12VideoDecoder`）とソフトウェアフォールバック。オーディオトラックはオーディオエンジンに多重化されていない。
- **ナビゲーション** — オフメッシュリンクは Recast のベイクでまだ生成されていない（ランタイムのトラバーサルハンドシェイクは存在する）。
- ネットワーキング: 未実装。
